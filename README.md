# 顔モザイク

画像・動画の顔をAI（Google MediaPipe Face Detector）で自動検出してモザイクをかけるWebアプリです。
データは端末の中だけで処理され、外部には送信されません。AIモデルも同梱しているので、**オフラインで動きます**。
PWA対応なので、スマホやPCに**アプリとしてインストール**できます。

**公開URL：https://kh6539313-cell.github.io/face-mosaic/**

## 起動方法（PC）

このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8080 を開きます。

```bash
python -m http.server 8080
```

## アプリとしてインストール

- **PC（Chrome / Edge）**：アドレスバー右側の「インストール」ボタン
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「アプリをインストール」/「ホーム画面に追加」

スマホでインストールするには HTTPS で公開されている必要があります（GitHub Pages など）。
一度開けば、以降はオフラインでも起動できます。

## 使い方（画像タブ）

1. 画像をドロップ、クリックして選択、または Ctrl+V で貼り付け
2. 顔が自動で検出されてモザイクがかかります
3. 調整
   - 枠をクリック：モザイクの ON / OFF
   - 枠をドラッグ：移動 ／ 角をドラッグ：大きさ変更
   - 何もない所をドラッグ：モザイク範囲を追加（検出漏れの補完）
   - Delete キー / 「選択中の枠を削除」：枠を削除
   - 種類（モザイク / ぼかし / 塗りつぶし）、形、粗さ、範囲の広さ、検出感度を変更可能
4. 「画像を保存」で元の解像度のまま保存（枠は入りません）

## 使い方（動画タブ）

1分までの動画（MP4 / MOV / WebM）に対応。音声はそのまま残ります。

1. 動画を選ぶと、全フレームの顔を解析します（PCで動画の長さと同じくらい、スマホではその数倍）
2. 同じ人を追跡し、一瞬検出できなかったフレームも補ってモザイクをかけます
3. プレビューで確認・調整
   - 「検出された人」の一覧、または枠のクリックで人ごとに ON / OFF
   - 何もない所をドラッグ：動画全体に固定のモザイクを追加（移動・角で大きさ変更・Deleteで削除）
   - 検出感度を変えると、再解析なしで結果を更新
4. 「動画を書き出す」で MP4 として保存（4K はフルHDで書き出し）

Chrome / Edge / Safari の最新版が必要です（WebCodecs を使用）。

## ファイル構成

- `index.html` … 画面（タブ・レイアウト）
- `js/core.js` … 顔検出・モザイク処理・枠の操作（画像と動画で共通）
- `js/image.js` / `js/video.js` … 画像タブ / 動画タブ
- `js/main.js` … タブ切り替え・ドラッグ&ドロップ・オフライン対応の登録
- `manifest.json`, `icons/` … PWA（インストール）用
- `sw.js` … オフライン用キャッシュ。**ファイルを更新したら `VERSION` を上げる**こと
- `vendor/` … MediaPipe Tasks Vision 0.10.14（Apache-2.0）と顔検出モデル、Mediabunny 1.61.0（MPL-2.0、動画の読み書き）
