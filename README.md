# 顔モザイク

画像の顔をAI（Google MediaPipe Face Detector）で自動検出してモザイクをかけるWebアプリです。
画像は端末の中だけで処理され、外部には送信されません。AIモデルも同梱しているので、**オフラインで動きます**。
PWA対応なので、スマホやPCに**アプリとしてインストール**できます。

## 起動方法（PC）

このフォルダで次のコマンドを実行し、ブラウザで http://localhost:8080 を開きます。

```bash
python -m http.server 8080
```

## アプリとしてインストール

- **PC（Chrome / Edge）**：アドレスバー右側の「インストール」ボタン
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：メニュー →「アプリをインストール」/「ホーム画面に追加」

スマホでインストールするには HTTPS で公開されている必要があります（GitHub Pages など）。
一度開けば、以降はオフラインでも起動できます。

## 使い方

1. 画像をドロップ、クリックして選択、または Ctrl+V で貼り付け
2. 顔が自動で検出されてモザイクがかかります
3. 調整
   - 枠をクリック：モザイクの ON / OFF
   - ドラッグ：モザイク範囲を追加（検出漏れの補完）
   - Delete キー / 「選択中の枠を削除」：枠を削除
   - 種類（モザイク / ぼかし / 塗りつぶし）、形、粗さ、範囲の広さ、検出感度を変更可能
4. 「画像を保存」で元の解像度のまま保存（枠は入りません）

## ファイル構成

- `index.html` … アプリ本体
- `manifest.json`, `icons/` … PWA（インストール）用
- `sw.js` … オフライン用キャッシュ。**ファイルを更新したら `VERSION` を上げる**こと
- `vendor/` … MediaPipe Tasks Vision 0.10.14（Apache-2.0）と顔検出モデル
